# الأمان

## اللي شغّال دلوقتي
| الطبقة | بتعمل إيه |
|---|---|
| **قواعد Firestore** | الكورسات والمحاضرات والتأملات والإعلانات والواجب مقفولة تماماً على غير المسجّلين. الحماية دي على السيرفر مش في الصفحة، فمفيش حد يفتحها بالـ DevTools من غير دخول. |
| **حسابات بإدارة** | مفيش تسجيل ذاتي. الإدارة بس بتعمل الدارسين، وتقدر توقف أي حد فوراً. |
| **جلسة واحدة لكل حساب** | لو الحساب اتفتح من جهاز تاني، الجهاز الأول بيطلع تلقائي. بيمنع مشاركة الحساب. |
| **خروج تلقائي** | بعد 45 دقيقة خمول (`idleMinutes` في `config.js`). |
| **منع النسخ** | منع تحديد النص والنسخ والقص والسحب وزر الفأرة اليمين وطباعة الصفحة وحفظها واختصارات المطوّر. |
| **كشف أدوات المطوّر** | لو اتفتحت (F12 أو من قائمة المتصفح) بنكشفها بطريقتين، وبنمسح محتوى الصفحة نفسه مش بس بنغطيه. لما تتقفل الصفحة بتتحمّل من جديد. وكمان الصفحة بتتغطى لما التبويب يتخبّى أو PrintScreen يتضغط. |
| **النص مش في كود الصفحة** | كود الـ HTML اللي بيظهر لأي حد (View Source) فاضي من المحتوى. النصوص بتتحمّل بعد الدخول بس. |
| **منع الفهرسة** | صفحات المحتوى مش بتظهر في جوجل. |

## اللي مش ممكن أي موقع يمنعه (لازم تعرفه)
- **تصوير الشاشة بالموبايل أو بكاميرا خارجية.** ملوش حل تقني.
- **تسجيل الشاشة بالبرامج.** المتصفح مفيهوش طريقة تمنعه. فقط DRM مدفوع بيسوّد الصورة على بعض الأجهزة.
- **قفل الـ inspect 100%.** المتصفح بتاع الدارس تحت سيطرته، فشخص متمكّن (متصفح تاني، إضافة، سكريبت) ممكن يلف على الكشف. اللي بنعمله إنه يبقى مش متاح لأي دارس عادي.
- **وانت بتطوّر الموقع:** اقفل `devtoolsGuard` في `config.js` (خليه `false`) علشان تقدر تفتح أدوات المطوّر. ارجّعه `true` قبل النشر.
- **ملفات الـ PDF على Drive:** لو دارس بعت رابط الملف لحد، الرابط بيفتح. ترقيتها لتخزين خاص بروابط مؤقتة ضمن المرحلة المتقدمة.

## قفلة إضافية مطلوبة منك (10 دقايق)
1. **قيّد مفتاح Firebase على نطاقك:** Google Cloud Console ← APIs & Services ← Credentials ← الـ Browser key ← **HTTP referrers** ← ضيف `https://USERNAME.github.io/*`.
2. **Authentication ← Settings ← Authorized domains:** سيب نطاقك بس.
3. **كلمات المرور:** استخدم اللي بيولّدها السكريبت (10 حروف عشوائية). متبعتش كلمة المرور في مجموعة عامة.
4. **لما حد يسيب الدراسة:** الإدارة ← الدارسين ← إيقاف.
5. **متحطش** `serviceAccount.json` ولا `credentials.csv` على GitHub (متحطين في `.gitignore`).
6. **اختياري، أقوى:** فعّل **App Check** (reCAPTCHA v3) من Firebase لمنع السكريبتات الآلية.

## تفعيل جديد: لازم تنشر القواعد
القواعد اتغيّرت (كل المحتوى بقى مقفول، وفي جلسات). **انسخ `firestore.rules` في Firebase ← Rules ← Publish** وإلا القفل مش هيشتغل.

## المرحلة المتقدمة (بعدين): الفيديو والـ PDF المحميين
- مكان الفيديو جاهز في الكود (حقل `videoId` ومشغّل داخل الموقع)، بس مقفول لحد ما نفعّله.
- الخطة: Bunny Stream برابط مؤقت لكل مشاهدة + منع برامج التحميل، ومعاه Cloudflare Worker مجاني يتأكد إن الدارس مسجّل. التكلفة تقريباً من 1 دولار شهرياً (راجع الأسعار الحالية قبل التنفيذ).
- DRM كامل بيسوّد تسجيل الشاشة: إصدار مدفوع مرتفع التكلفة، وده قرار نأخده بعدين.
- نفس الـ Worker ممكن يخدم الـ PDF من تخزين خاص بدل Drive.
