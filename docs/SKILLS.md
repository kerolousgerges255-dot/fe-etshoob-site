# الـ Skills المثبّتة في المشروع

الـ skill ملف تعليمات بيتحمّل لـ Claude لما تفتح المشروع (في Claude Code أو Cowork)، فيشتغل بخبرة متخصصة بدل ما يبدأ من الصفر. **مش بتأثر على الموقع نفسه** ولا بتتنشر على GitHub Pages (المنشور فولدر `site/` بس).

| Skill | بتعمل إيه لينا |
|---|---|
| **fe-etshoob-site** (خاصة بمشروعنا) | بتعرّف Claude بنية الموقع وقواعد الأمان وإزاي يختبر قبل ما يسلّمك. دي أهم واحدة. |
| **senior-backend** | تصميم قواعد البيانات والصلاحيات والمصادقة وأمان الباك إند. |
| **senior-devops** | مسار النشر الآمن والمراقبة. |
| **ci-cd-pipeline-builder** | بناء فحوصات تلقائية على GitHub قبل ما أي تعديل ينزل على الموقع. |
| **senior-security** | تحليل التهديدات (مين ممكن يهاجم إيه) وفحص الأسرار. |
| **env-secrets-manager** | منع تسريب مفاتيح Firebase وكلمات المرور وطريقة تغييرها. |
| **javascript-pro** | كتابة جافاسكريبت حديثة ونضيفة. |
| **secure-code-guardian** + **security-reviewer** | كتابة كود آمن ومراجعة أمنية بتقارير بدرجات خطورة. |
| **code-reviewer** | مراجعة أي تعديل قبل ما ينزل. |
| **test-master** + **playwright-expert** | الاختبارات: اللي بتتشغل في المتصفح والاختبارات العادية. |
| **debugging-wizard** | لو حاجة باظت، بيدوّر على السبب بمنهج. |
| **devops-engineer** | النشر والفحوصات التلقائية. |
| **fullstack-guardian** | أي ميزة جديدة تتبني بأمان من الواجهة للباك إند. |

## إزاي تستخدمها
- **Claude Code / Cowork**: افتح فولدر المشروع. الـ skills بتتحمّل تلقائي من `.claude/skills/`، وكمان `CLAUDE.md` بيوجّهه.
- **هنا في الشات**: ارفع الـ zip وقلّي اللي عايزه، وأنا بقرا الـ skill الخاصة بالمشروع.
- أي طلب زي "راجع أمان الموقع" أو "جهّز فحوصات تلقائية قبل النشر" Claude هيستخدم الـ skill المناسبة لوحده.

## مصدرها وأمانها
المصدر والرخصة في `.claude/skills/SOURCES.md`. مجموعتين: alirezarezvani وJeffallan (الاتنين MIT). فحصتها يدوي وبأداة فحص قبل التثبيت، ومفيش فيها حاجة بتتصل بالنت أو بتبعت بيانات.
> الـ skills العامة مكتوبة لمشاريع أكبر (AWS وKubernetes). Claude بياخد منها اللي بيناسب مشروعنا بس.
